# BlueSCSI Mini PCB Clone

A compact STM32-based PCB clone of the BlueSCSI project - a personal hardware experiment.

## Overview

This is a smaller form-factor version of the BlueSCSI hardware design, created as a fun PCB project experiment. It implements the core BlueSCSI functionality in a more compact layout.

## Important Limitations

⚠️ **This board lacks SCSI termination circuitry** - As a result, it does not work reliably on all machines. 

### Compatibility

- ✅ **Confirmed Working:** PowerMac systems
- ❓ **Limited Testing:** Other SCSI devices may or may not work depending on their termination requirements
